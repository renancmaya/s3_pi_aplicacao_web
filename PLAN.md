## Slide 2 – Tema do projeto
**Tema:** Aplicação para gestão financeira.
**Descrição:** Desenvolvimento de uma aplicação web voltada para o controle e gerenciamento de contas a pagar e a receber.

## Slide 3 – Definição do problema
A gestão financeira manual ou baseada em ferramentas inadequadas gera desafios como:
- Falta de visibilidade clara sobre o fluxo de caixa.
- Desorganização no controle de vencimentos e recebimentos.
- Dificuldade em gerar previsibilidade financeira.
- Dependência de planilhas complexas, que exigem conhecimento avançado e são suscetíveis a erros humanos.

## Slide 4 – Objetivo geral
Desenvolver uma aplicação web intuitiva para o cadastro, consulta, alteração e exclusão de movimentações financeiras. O sistema visa facilitar a organização e a análise de dados por meio de recursos de filtragem, pesquisa e cálculos automáticos de resultados.

## Slide 5 – Requisitos funcionais
A aplicação deverá permitir aos usuários:
- Cadastrar novos registros financeiros.
- Consultar o histórico de registros cadastrados.
- Alterar as informações de registros existentes.
- Excluir movimentações financeiras.
- Pesquisar registros por descrição, categoria, forma de pagamento ou conta financeira.
- Filtrar dados com base em data, categoria, forma de pagamento, conta financeira ou valor.
- Ordenar a listagem de registros por data, categoria, forma de pagamento, conta financeira ou valor.

## Slide 7 – Tecnologias previstas
**Tecnologias:** HTML5, CSS3, JavaScript e versionamento de código com Git/GitHub.
**Armazenamento:** A persistência dos dados será feita localmente utilizando a API LocalStorage do navegador, eliminando a necessidade de um servidor de banco de dados externo nesta etapa.

## Slide 8 – Considerações finais
Ao término deste projeto, espera-se entregar uma aplicação web funcional, com arquitetura organizada e interface amigável. A solução proporcionará ao usuário final uma ferramenta prática e autônoma para a gestão eficiente de suas finanças diárias.
